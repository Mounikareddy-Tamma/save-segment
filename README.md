# Saving Segment and add schemas under segment

A React-based project that provides a user-friendly interface for managing segments, including dynamic dropdowns

##  Features
-  Dynamic Select dropdowns with filtered, non-repetitive options
-  Responsive UI built with **React-Bootstrap** and **React-Select**
-  Clean component structure for scalability

---

## 🛠️ Tech Stack
- **React.js**
- **React-Bootstrap**
- **React-Select**
- **JavaScript (ES6+)**
- **CSS / Bootstrap 5**

---
